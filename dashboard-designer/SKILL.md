name: dashboard-designer
description: Design modern dashboards with strong hierarchy, analytics layouts, and data visualization structure.
---

When designing dashboards, prioritize information hierarchy and clarity.

Always structure dashboards into:

1. summary / overview section
2. key metrics cards
3. visual analytics (charts or progress indicators)
4. detailed sections

Balance **information density and readability**.

Use:

* metric cards
* progress indicators
* charts
* grouped analytics blocks

Avoid cluttered dashboards or equal-weight layouts.

Important metrics should always have stronger visual emphasis.
