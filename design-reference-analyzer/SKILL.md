---
name: design-reference-analyzer
description: Analyze UI screenshots, design references, or frontend layouts and extract their design structure and philosophy.
---

When the user provides a UI reference (screenshots, dribbble images, figma frames, or UI code), analyze the design before generating anything.

Always break the design into these layers:

1. Layout structure
2. Spacing system
3. Typography hierarchy
4. Color palette
5. Component shapes
6. Visual hierarchy
7. Interaction patterns

Explain the **design philosophy** behind the interface.

Then extract the **design DNA** and produce:

* a layout blueprint
* reusable component structure
* spacing rules
* hierarchy structure

Do not copy the design directly. The goal is to understand the design system behind it.
